# ZRCC
An inexpensive RC2014-compatible, CP/M ready Z80 SBC
There are two versions of ZRCC:
- [Rev1.1](rev1.0_rev1.1) is current version running at nominal 22MHz clock
- [Rev1.3](rev1.3) is designed for overclocking experiment with faster RAM and Disk-on-module.  33MHz operation is possible
- Rev1.2 does exist, but is undocumented.
